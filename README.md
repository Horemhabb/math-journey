# Math Journey

A small math game for the browser (English version of "Rechenreise"). It runs entirely on the device, with no account and no server.

The chicken pictures come from Jean Bungartz, "Geflügel-Album" (1885), Badische Landesbibliothek Karlsruhe, via Wikimedia Commons (category "Geflügel-Album (Jean Bungartz, 1885)") and the library's digital collections. They are in the public domain and were only resized and cropped to the plate.

Spoken text uses the device's built-in English voice. Nothing is sent to any service while playing.
